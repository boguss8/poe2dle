# PoE2dle roadmap

Goal: a fully polished, daily Path of Exile 2 guessing site. The **Skill Gem game is the front page (`/`)**; other games plug in later next to it.

Legend: `[x]` done · `[ ]` open · `(later)` deliberately postponed.

## Design decisions

- **Guess pool**: skill gems (active, meta and **Spirit**) that are released, have an icon, are not dev placeholders (`[DNT]`, `Playtest`, `Unique*`, `{0}` templates) and are not basic weapon attacks (`PlayerDefault*`). Duplicate names are collapsed to one entry. Support gems are a separate game later. The pool is generated by `pnpm build-skill-pool` into `data/skill_pool.json`, so the client never ships the 1.3 MB raw gem file; tooltip text lives in `data/skill_details.json` and is fetched on first hover.
- **Spirit gems** (poe2db's "Spirit Gems", 53 of them) = craftable gems whose skill reserves Spirit, excluding the skeleton minions. They get their own category.
- **Unlimited guesses + "Give up"**, like other attribute-guessing dles. There is no hard lose state; the stats track guesses-to-solve, and giving up breaks the streak.
- **One answer per UTC day**, derived from a seeded shuffle of the sorted pool, so every player gets the same skill and no skill repeats until the pool is exhausted.
- **Clues** (columns): Category (attack, spell, spirit, minion, companion, buff, curse, meta, utility), Attribute, **Source** (where the skill comes from or what it needs: the weapon/spell group a gem is cut for — Bow, Mace, Elemental, ... — the item that grants it (Wand, Staff, Sceptre, Shield), Ascendancy, Runeforged, or Other when the data doesn't say), Damage, Delivery (projectile / area / melee), Tier, Mana (level 1), Cast time, Version (PoE2 patch the gem first appeared in) and Mechanics (remaining tags). Number clues show a higher/lower arrow. Source replaced the plain *Weapon* column, which repeated *Attribute* (0.75 normalised mutual information) and could not tell Ascendancy skills such as Supporting Fire apart from other uncut-less skills; *Type* (91% "active") and the old catch-all *Tags* column were dropped.
- **Source detection**: Ascendancy = the gem id contains "Ascendancy" (51 skills); Runeforged = base item tag `runeforged` (23); item-granted = a base item lists the gem in `skills_granted` (35); 74 skills have no origin in the data and show "Other".
- **Hints** (opt-in, remembered per day, noted in the share text): reveal the first letter after 3 guesses and the icon after 6 (`lib/games/skill/hints.ts`).
- **"Tier"** is RePoE's `crafting_level`: it is the "Tier: N" line on the in-game gem tooltip, and the Weapon/Tier grid on poe2db's gemcutting tab.
- **Version** comes from the RePoE data repo's git history: for each PoE2 minor release (0.1 – 0.5) the newest `skill_gems.json` export is compared and a gem gets the first release that contained it as *released* (`pnpm build-skill-versions`). Granularity is the minor version; hotfix patches (0.3.1 ...) count as their minor.
- **Accessible feedback**: status is never colour-only (icons, matched-chip inversion, arrows, screen-reader text).
- **Progress lives in first-party cookies** (compact encoding, see `lib/games/skill/codec.ts`), read through `useSyncExternalStore` so there is no hydration mismatch. A consent choice decides the lifetime: Accept = up to 400 days (streaks survive), Session only = cleared when the browser closes. No analytics or third-party cookies.
